# Предсказания

Предсказание в вероятностной регрессии — это не только одно число. Для каждого нового наблюдения модель сначала вычисляет предикторы `eta`, затем параметры `theta` и тем самым задаёт условное распределение ответа.

В нормальном location-scale случае это означает предсказывать `mu_i` и `sigma_i`; из них можно получить квантили, интервалы и вероятности событий.
